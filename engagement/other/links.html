Explain the difference between an absolute link and a relative link. Why would you use relative links?

Absolute links are links to another webpage outside of your domain. Relative links are links within the website. Relative links could be siblings or a child. You would want to use relative links if it is in the same domain. For example in the navigation links, for a website like amazon. you would want your customers to open to an amazon product not a product in temu.

Do links always need to be inside a NAV tag?

No, but it would make sense for your nav tag to have links on it. It helps your users how to navigate the pages in your website

List the 3 rules with relative links.

  1. Siblings are in the same folder
  2. child is folder/file.html
  3. auntie/unlce uses ../links.html
  4. Dont start with /. This is going to break your link
