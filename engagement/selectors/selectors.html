List out the different ways to select an item.

You can use different CSS selectors such as element selectors, class selectors, ID selectors, and attribute selectors to target and style specific elements on your webpage.

What is the difference between an ID and a Class?

An ID is used to uniquely identify a single element on a webpage, whereas a class can be applied to multiple elements. Making classes more flexible and reusable is a common practice in CSS.

What is the difference between a SPAN tag and a DIV tag?

A span tag is used to inline elements within a line of text, while a div tag is used to create block-level elements. It stars on a new line and takes up the full width available.

What is the difference between a DIV tag and a HEADER, MAIN, or FOOTER?

A div tag is a generic block-level container, and has no meaning. While header, main, and footer are semantic elements that provide meaning to the content they contain.

What are the different ways to select a color?

You can use colornames, hexadecimals, RGB, and HSL values to select and apply colors in CSS.
