Explain the difference between inline, embedded, and external CSS.

Inline css is written directly inside the html element. Embedded is written inside the head tag. External CSS is the best practice, it is written in a separate file.

Explain why you should only use external CSS.

You should only use the external CSS to be efficient and develop industry standard practice. It helps you how to organize your CSS into one file only.

What is a selector used for?

The selector is what is used to select wich tags will have these certain properties of CSS
