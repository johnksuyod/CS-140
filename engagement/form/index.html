The form tag has an "action" attribute. What does it do?

It acts like a link and opens another html file when you submit the form.

The form tag has a "method" attribute. What does it do?

It determines the method the browser uses to send the from from to the server.

How do you fill in a form control with a pre-set value, and how is that different from a placeholder? Answer for each of these: text box, textarea, select box, checkbox, and radio button.

For the text box you use the value attribute. For textarea you place a text between the opening and closing tags. For select box you add the boolean selected to a specific option you want to select as the default. For checkbox you add the boolean checked. For radio, you also add the boolean checked.
