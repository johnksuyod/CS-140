What kind of photos are good to encode using JPEG?
JPEG is great for images or photographs that need to be compressed for smaller file sizes, fast sharing, and wide compatibility across different platforms.
What kind of photos are good to encode using GIF?
GIF is great for simple animations and images.
What is unique about the PNG format?
The PNG format supports transparency.
How do you resize your photo to the size it should be displayed?
You can resize your photo using photo editing software or by using CSS. However, resizing with CSS only changes the display size, not the actual file size.
Why should you resize photos using photo editing software instead of resizing it using CSS?
Photo Editing Software decreases the file size, allowing pages to load much faster. Resizing with CSS only changes the display size, not the actual file size.
