Questions

What is normal flow in HTML?

The normal flow of in HTML is from top to bottom and felt to right. Each block tag takes the entire horizontal width of the screen.

What does float do? Why do you need to clear the float?

Float allows you to place the elements on the left or on the right. It's main use is to allow the inline elements to wrap around it. Just like how an image is wraped arround by text in a magazine. You need to clear it to make a clean format or else the elements underneath it will occupy the space above them

What do absolute, fixed, and relative do?

They are responsible for the position of an element. Relative means the position of the element will be it's original position. Absolute positions removes the element from its original flow. It also scrolls with the page. Fixed is used to fixed the position of an element so that even when you scroll it is still there.

How can you make nice navigation buttons for mobile devices?

Make them a lot bigger by making them into block tags and add some padding, background color, and boarder.
