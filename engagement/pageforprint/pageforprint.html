Why is the viewport meta tag important?

The viewport meta tag is responsible for adjusting the dimensions of the webbroweser to the screen of the device it is being viewed. Without it the webiste is assumed to be build for web browers with a default with of 980px

How can you adjust the CSS for printing?

You can adjust he CSS for printing by adding a @media print, also known as a media query

When would you want to adjust the CSS for printing?

You would want to adjust the CSS for printing when the contents of the webbrowser is an article, a document, or a tutorial, or a course (just like canvas).

Why do we need a viewport meta tag?

We need the view port meta tag so that the dimensions of our web borwser will adjust to the screen of the devied it is being viewed.

When you select the same tag twice, and in one of them you say "flex-direction: column;" and the other says "flex-direction: row;", which one takes priority?

The last(lowest) one that you did

How do you change the CSS for a web page displayed on a phone?

You use a media query and set the max-width or min-width, depending if you're going from mobile to desktop or destop to mobile. Then you apply the styles you want to do.

Working from desktop to mobile, I set my max-width to 600px. I chose this breaking point because I read that most mobile devices are below or close to this width.
