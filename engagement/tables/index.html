When do you use a table?

You use the table element when you need to display data in a spreadsheet-like format.

When do you not use a table?

You do not use a table for page layout.

When do you need to do extra work for table accessibility?

You need to do extra work for table accessibility when the table conatins complex data. In engagement, there were mergecells and multilble header levels. We used appropirate attributes like scope, rowspan and colspan.

Why don't we use the border attribute?

That's old school HTML. We now use CSS to style tables.

What is the easiest way to color every other row a different color?

Use the pseudo-class :nth-child(odd) or :nth-child(even).

What does the value in the parentheses of your structural pseudo-class mean? Give one other value you could use and which rows it would select.

The value in the parentheses of a structural pseudo-class refers to the position of the element relative to its siblings. For example, :nth-child(2) would select the second child element. You can also use the fomula method :nth-child(an + b) to customize the selection.
