1.What is JavaScript? How did it get its name?

JavaScript is a programming language used to change and modify webpages. Netscape originally created it, and it got its name through a marketing partnership with Sun Microsystems to capitalize on Java's popularity.

2. What are the two ways you can run JavaScript?

The two ways you can run JavaScript are in a web browser and using a runtime like Node.js.

3. What is jQuery? Is it still popular today?

jQuery is a JavaScript library. It was widely used in the past to build websites, and while it still runs on many older sites today, developers rarely use it when building new websites.

4. What is the most popular front-end js library today?

React is the most popular front-end JavaScript library.

5. How does your code prevent the form from being submitted? Why do we need to prevent it?

event.preventDefault() prevents the form from submitting. We need to prevent it so that we can validate the inputs first, and to stop the page from navigating to the URL specified in the action attribute.

What is AJAX?

AJAX (Asynchronous JavaScript and XML) is a technique in web development to send or receive data from a server.

Why do you put your JS Code in a separate file?

You place your JS Code in a separate file to make the code you wrote look cleaner and easier to read. Like CSS you can also make it reusable through multiple HTML pages.

How do you use the inspector (DevTools) to debug your JavaScript? How do you find the line number of an error?

You use the Console Tab of the Chrome Dev Tools to view runtime errors, syntax errors, and output. To find the line number of error you use the Sources Tab.
