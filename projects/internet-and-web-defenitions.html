How are the Internet and Web different?

The internet is what allows computers to communicate with each other, while the web are web pages that we can access though the internet. It's an information that a computer can get from another computer through the internet.

ASCII and Unicode

Computers only under stand zeros and one. We use ASCII to represent human language such as letters to be able to communicate with computers. For example the letter "A" is represented by 01000001 in ASCII. The Unicode is more advanced version of ASCII that can represent more characters and symbols from different languages.The letter "A" is U+0041.

Domain Name

Domain name is the name that is given to a webpage or a website in the internet. Example the domain name for Google is google.com

HTTP

HTTP stands for HyperText Transfer Protocol (http://). It is the process how a web browser communicates with a web server to acess a webpage. The information that we seen in our web browser are stored in web serrves. The web browers fetches that information from the web server and displays it in our web browser. When we type google.com in our web browser, the web browser sends a request to the web server of google.com. The server then receives the request and sends back the information to the web browser. Then the web browser will display it to our screet. This is the process that we call HTTP.

HTTPS

HTTPS stands for HyperText Transfer Protocol Secure. Its a secure version of HTTP. It beings with https:// instead of http://. It encrypts the information sent to the web server and the information sent back to the web browser. For example, you want to log in to your facebook account. You type your username and password. Your information is sent to the web server of facebook.com. Your information (username and password) is encrypted so that no one like a hacker can read your information (username and password) as it is sent to the web server.

IP Address

Like houses, computers have unique address on the internet. The IP address is a numeric address that uniqely identifies a computer on the internet. For example when your browsers send a request to acess a server, the browser sends a request to the IP addresss of the server. then the server sends back the information to the IP address of computer. There are millions of request being done in the internet every second. The IP address is what allows computers to know where to send the information and where to receive the information.

DNS

IP address is in a numeric format. It would be very hard to remember the IP address of all our favirote websites, let alone type them. That is why we used domain names. The DNS or the Domain Name System is a system that translates domain names to IP addresses. For example you want to watch youtube. You type youtube.com in your web browser. The DSN translates youtube.com to its IP adress and then sends the request to the IP address of youtube.com. The server then sends bakc the information to the IP address of your computer.

W3C Recommendations

W3C (World Wide Web Consortium) is the organizaion responsible for developing guidllines and standards for the web. For example you want to create a web page using HTML and CSS. You must follow the W3C recommenations to make sure the the webpage you created is compatible with all web browers. If you don't your webpage may not be displayed correctly.

XML, XHTML, HTML, HTML5

The XML (eXtensible Markup Language) is a programming language used to store and transport data. The language is designed to be readable for humans and computers. It is a W3C recommendation.The XHTML (eXtensible HyperText Markup Language) is a programming language that combines the features of HTML and XML. The HTML (HyperText Markup Language) is the programming language used to create websites. It is responsible for displaying text, images, and other content on the web. HTML5 is the latest version of HTML.
